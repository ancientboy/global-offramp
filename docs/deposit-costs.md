# BSC充值与净到账费用展示

新增 USDT-BSC（BEP20）充值，默认优先BSC。TRC20选项保留。充值金额表示用户支付总额；平台按支付方实际净结算金额增加余额，不补贴成本，也不重复扣一笔手续费。

充值单创建后，服务端读取官方订单状态及 outcome_amount，保存净到账预估。页面显示支付总额、预估总成本、预计到账；用户确认费用后才显示地址、二维码和Memo。报价金额或地址发生变化，确认自动失效。报价未到、金额异常、币种或结算路线不匹配时不展示付款地址。历史列表不直接展示地址，需打开费用明细。

费用是同一稳定币支付总额减官方预估净结算额，包含该单处理及网络成本。外部钱包另收的转出费不包含在内；不拿出金网络费接口的数值替代整笔收款成本。浮动报价仅作参考，最终仍以官方完成状态的实际净结算额入账，保留微单位保守截断。`is_fee_paid_by_user` 保持 false，避免供应商切换固定汇率收费模式；费用已通过净额入账由用户承担。

当前明确审核的USDT路线为 usdtbsc→usdtbsc、usdttrc20→usdtbsc。供应商全局结算配置没有修改。USDC Base仍沿用严格同网络校验。每张新单保存 settlement_network，之后应用角色不能改它；历史空值继续使用原同网络检查，不能由新配置追溯放宽。若要改成TRC→TRC，需另行核对商户结算配置和新报价。

迁移011只新增 settlement_network 与 cost_quote，不改余额或旧订单。新单报价可能比地址延后返回：首次创建后主动查询，前10分钟未取得报价的等待单每15秒重查；前端每10秒读取。失败或超时保留原订单，不重复创建。既有最终状态、IPN验签、归属、固定幂等和防重复入账保护保留。费用预估从不直接入账。

验证包括BSC净额入账、批准的同资产跨链路线、未知路线拦截、历史路线不变、报价延迟、报价变化重新确认、错误费用阻止二维码展示及重复结算幂等。生产接口验收使用独立HTCHECK未付款订单，没有转币或增加用户余额。100与10,000USDT样例费用以创建时官方动态报价为准，不作为固定价格写入产品。
