# 管理员统一流水与客户资金详情

管理员“资金管理”首屏新增统一资金流水；“用户与商户”新增完整客户目录与详情。所有接口仅供已登录的管理员读取，不增加自动转账、余额调整或数据改写接口。

## 流水范围与口径

包括 NOWPayments 充值、保留的模拟充值、客户提现、结汇订单、订单退款、服务商结算及其余账本凭证。业务申请即使未入账也会显示；汇总只计入已完成金额。充值按真实已记账净额，少付申请金额与净到账额分列。模拟充值独立统计。结汇支出为含报价手续费的总支出，同时展示本金、客户汇率、目标法币金额、报价服务费/渠道费和已记账净手续费。退款冲减的已记账手续费采用净额。

支持姓名、登录标识、用户编号、业务单号、钱包地址及交易参考号搜索，按类型、源币种或目标法币、处理状态、创建日期过滤。日期筛选按北京时间、结束日期包含当日。没有历史申请时间的旧订单退款明确显示“时间未记录”，不补造时间。各币种独立汇总，不进行隐含折算。

每条业务展开关联凭证、借贷科目及钱包可用余额的前后值。余额按不可变账本行的记账顺序重建，区别于按申请创建时间排序的业务列表；冻结申请不是外部转账。每张凭证关联一个业务或归入其他账务，避免重复展示、重复统计。充值未持久化链上交易哈希时仅显示支付服务编号，不猜测哈希。来源为旧模拟接口的入金保留模拟分类。

逐笔 CSV 导出应用全部当前筛选，不限于当前页，包含金额、状态、业务关联及可用余额变化。超过 10000 笔拒绝导出并提示缩小范围，避免静默截断；CSV 文本防公式注入。JSON 每页最多 100 笔，默认 25 笔。

## 客户信息

客户目录包含所有已登记客户，未产生订单的客户和登录停用客户同样可见，可搜索、按类型及状态过滤、分页。资料包括客户编号、姓名、个人/企业类型、登录邮箱或用户名、业务状态、登录启停、注册时间、最近成功登录、验证器绑定状态和推广归属。无历史资料时显示未记录，不伪造账户状态。

资金按 USDT / USDC 分别显示可用余额、结汇冻结、提现冻结及合计，同时展示累计收支、订单数、已完成订单数及该客户专属流水。全部余额由账本汇总，不从申请金额推测。收款账户默认掩码，已绑定完整资料的账户由管理员点击后通过现有受权限保护的接口查看。

API 仅选择展示必要字段，不返回密码散列、验证器密钥、恢复码、银行账户密文、私钥或回单原始文件。完整收款资料不进入统一流水或 CSV。

## 一致性与范围

`GET /workspace/api/admin/finance/transactions`，`GET /workspace/api/admin/customers`，`GET /workspace/api/admin/customers/:id` 均为只读。资金、用户和业务关联来自同一 PostgreSQL REPEATABLE READ READ ONLY 快照；金额使用定点字符串和整数运算，保留稳定币六位精度。账本平衡及余额统计不等同于外部钱包资产证明。

当前系统业务主数据仍使用聚合 JSONB；报告读取必要投影和账本，内存中建立关联索引并筛选分页，未宣称针对海量账本已完成性能验收。后续规模扩大需转入独立只读投影和数据库分页，保留上述口径与权限。
